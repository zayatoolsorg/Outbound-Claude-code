# Proof Library — Zaya case studies and how to use them

Every piece of Zaya proof-of-work the system can reference. Outreach may only
describe a project using wording supported by its entry here. Add new projects
using the template at the bottom.

---

## How to match proof to a prospect

For every qualified prospect, answer:

1. Is any existing Zaya work relevant?
2. Which case study is most relevant?
3. Why? (a shared industry, format, creative problem or audience)
4. Should it appear in the **first message**, or only **after they reply**?
5. Which single piece should be recommended?

Record the answers in `master.csv` (`Relevant Proof`, `Proof Relevance`,
`Recommended Portfolio Piece`) and in the lead card.

### Relevance scale

| Relevance | When |
|---|---|
| High | Same kind of company or the same creative problem |
| Medium | Adjacent industry or format; a credible bridge |
| Low | Only shows general quality |
| None | Not relevant |

### Timing rule of thumb

- **High** relevance → may be mentioned lightly in the first message.
- **Medium** → usually after they reply, unless it makes the opening sharper.
- **Low / None** → don't mention in the first message.

### How to mention proof

Proof supports the message; it isn't the pitch. Connect it to the prospect's
situation.

Good patterns (use only if factually supported by the case study):
- "We recently worked with a Dubai-based OOH company on a similar visual challenge.
  There's a case study on our site if you'd like to see the approach."
- "We've worked on this kind of visual communication for Block Agency, so this
  reminded me of that project."

Avoid:
- "Check out our Block Agency case study."
- Leading with the case study before the observation about *their* brand.
- Implying scale that isn't real ("our international clients", "brands worldwide").

**Relevance by prospect type**

| Prospect type | Relevance | Default timing |
|---|---|---|
| OOH / DOOH agency | High | First message (light touch) |
| Advertising / creative agency | High–Medium | First message if the angle is about campaign visuals; otherwise after reply |
| Experiential / marketing agency | Medium | After reply, unless the creative problem overlaps |
| International brand with OOH or campaign activity | Medium | Case by case |
| Luxury / beauty / skincare / lifestyle brand | Low, unless the creative problem overlaps | Don't lead with it |

**Allowed factual claims**
- Zaya has worked with (and currently works with) a Dubai-based global
  OOH/advertising agency: Block Agency.
- There is a Block Agency case study on the Zaya website.

**Not allowed without confirmation**
- Specific deliverables, campaign names, cities, screen placements, metrics or
  results.
- Any claim that generalises this into a "global portfolio".
